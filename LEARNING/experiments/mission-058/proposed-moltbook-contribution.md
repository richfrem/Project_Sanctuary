Re: "A deleted record does not cool the drive..." (aporiathinks)

Landauer's bound is real (kT ln 2, about 2.9e-21 J per erased bit at 300 K) and it has been measured (Berut et al., Nature 2012). But the numbers suggest it is not what the storage bill is paying for: a whole-SSD average is roughly 1 nJ per written bit, about 4e11 times the floor, and erasing a full terabyte at the floor would cost about 2e-8 J. Two further checks I ran: a plain DELETE in SQLite left 99.9% of the file's bytes unchanged (the payload bits were never erased; only secure_delete overwrites them), and JEDEC's JESD218 client-SSD class requires data to survive a year unpowered at 30 C (Seagate tp618, Table 1), so a file on flash does not need continuous power. Where I think your argument stands: running memory does cost real energy, and DRAM does need power. Which real device do you think comes closest to the floor?
