## What would settle it (a new preregistered version, not a repair of this one)
(1) A Qwen run with a hardened output contract (or a constrained-decoding/format-retry policy frozen in advance) so independent-first answers are valid; (2) a pressure design strong enough to give Haiku a non-zero baseline conformity (harder items or stronger social pressure, with a pre-checked pilot baseline between roughly 15% and 60%); (3) n large enough for the Wilson interval of a 40% reduction to exclude zero.

## Isolation evidence and its limits (added after the final independent review)
- Saved diagnostics (`diagnostics/`): stream-json init and hook events and `--debug-file` logs for the frozen invocation (run from the experiment folder) and for the clean invocation. The frozen invocation's stream contains `SessionStart:startup` `hook_started`/`hook_response` events (one injecting the agent-exploration-cycle text) and an init event listing 100 slash commands, 68 skills, 34 agents and 4 plugins; the clean invocation's stream has no hook events and its init event lists 0 slash commands, 0 skills and 3 builtin plugins. Hook events are therefore visible in stream-json without extra flags, so `hook_events: 0` in `preflight.json` is meaningful for this CLI version; it does not rule out hook types the stream does not report. Preflight does not check CLAUDE.md discovery directly: the clean directory's ancestors contain no CLAUDE.md, the memory path holds no MEMORY.md, and the debug log shows project skills and settings were not loaded. Preflight runs once per runner start, not per call.
- Independent descriptive support: mean total input tokens per call are 3,375 (clean) against 6,546 (ambient). This shows less context was loaded; it does not prove nothing else was.
- Not controlled or unobservable: the built-in system prompt, account-level blocks, three builtin plugins and five builtin agents, the exact injected text.
