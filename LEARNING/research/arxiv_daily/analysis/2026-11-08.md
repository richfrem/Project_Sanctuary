# arXiv analysis

## Relevance to existing missions

1. **Phantom Consensus** (2611.08971v1): Supports MISSION-004, MISSION-009, and MISSION-061. It measures LLMs shifting public decisions under ambiguous social signals while misreporting peers' private judgments, which directly targets the consensus-following failure those missions aim to reduce.
2. **PhysioWave-T** (2611.08969v1): none. It concerns biosignal tokenization and has no bearing on the current missions.
3. **More with Less: Agent-Skill Workflow for Scientific Code Translation** (2611.08947v1): Offers a method to MISSION-033 and MISSION-052. Its agent-skill workflow with differentiated repair strategies is a relevant pattern for orchestrated multi-worker delivery.
4. **Flex-RSI** (2611.08946v1): Supports MISSION-054 and MISSION-049. It benchmarks whether agents improve their harness (prompts, tools, memory, control loop) from task feedback, which is the closed-loop repair question those missions raise.
5. **Ordered Policy Optimization** (2611.08936v1): none. It is an RL optimization method with no link to current missions.

## Impact on the project

- Paper 1 suggests that multi-agent review or consensus steps should record each agent's independent judgment before exposure to peers, and should check that the recorded judgments support any claimed consensus. This matches the independent-first pattern in MISSION-009.
- Paper 4 suggests that harness changes (prompts, skills, hooks) should be evaluated as first-class artifacts with their own before/after measurements, not just the model's answers.

## Improvement ideas

1. When a multi-agent review reports consensus, have the merge or review script compare the reported consensus against the recorded independent verdicts and flag any mismatch.
2. Add a small check to skill-workflow reviews that records which repair strategy was applied to each failure, so repairs can be audited per category.
3. Log each harness change (prompt, skill, or hook edit) alongside the failure it targeted, so its effect can be measured later.

## New mission seeds

1. **Paper:** http://arxiv.org/abs/2611.08971v1. **Question:** Does requiring each agent to record an independent judgment before seeing peer conclusions reduce the rate at which a reported consensus contradicts the recorded private judgments? **First step:** Using existing review logs or a few synthetic 3-agent cases, count how often the reported consensus disagrees with the recorded independent verdicts, with and without the independent-first record.
2. **Paper:** http://arxiv.org/abs/2611.08946v1. **Question:** Do harness edits that are logged with their targeted failure produce measurable improvement on the same failure class in later runs? **First step:** Take the last ten harness changes recorded in the mission history, and for each, check whether the targeted failure recurred in the following runs.

*Every point above is based on abstracts only. None of the papers' full texts were read, so claims about their methods and results are provisional.*
