# arXiv analysis

## Relevance to existing missions

1. **Medical Image Segmentation: Foundation Model Adaptation versus Task-Specific Training** (http://arxiv.org/abs/2611.14519v1): none. It concerns medical imaging and foundation-model adaptation, which no current mission covers. The closest mission is MISSION-010 (causal discovery) only by general "claim test" framing, which is too weak to cite.

2. **Toward Foundation Detection Models via Example-Based Grounding in EM-DETR** (http://arxiv.org/abs/2611.14518v1): none. Medical lesion detection is outside the scope of the existing missions.

3. **Contrastive Discovery: Open-Ended Scientific Discovery over Competing Explanations** (http://arxiv.org/abs/2611.14514v1): MISSION-010, MISSION-014. The abstract suggests comparing a hypothesis against alternatives rather than only its complement, which bears on causal discovery by intervention and on information-gain experiment selection.

4. **Comparative Analysis of Agent Evaluation Frameworks** (http://arxiv.org/abs/2611.14493v1): MISSION-061, MISSION-041, MISSION-035. It compares LLM-judge, red-team, and deterministic evaluators on frozen traces, which touches evaluator validity and falsification-by-tests.

5. **ReTrace: Distilling Tool-Using Agents into Planner-Free Workflows** (http://arxiv.org/abs/2611.14492v1): MISSION-042, MISSION-064. It replaces per-step LLM planning with fixed workflows, which bears on bounded local execution and on whether added planning edges help or harm.

## Impact on the project

- Evaluation: the framework comparison (item 4) suggests that deterministic checks and LLM judges should be reported separately rather than merged into one verdict. This is a practice worth reviewing in evaluation workflows.
- Orchestration: ReTrace's planner-free approach suggests that fixed, typed procedures could cut per-run model calls for recurring operations. This is a candidate architectural idea, not a change to make now.

## Improvement ideas

1. When a mission verdict relies on an LLM judge, also record a deterministic check result in the same entry, so disagreements are visible.
2. Add a "competing explanation" field to hypothesis briefs (what the evidence would support instead), following the contrastive framing in item 3.
3. For recurring SOPs, record the step sequence once as a typed list and reuse it, rather than re-planning it each time.

## New mission seeds

1. Does comparing a hypothesis against explicit alternatives, rather than only its complement, identify the correct explanation more often in a small synthetic causal task? First step: generate 20 hidden-graph fixtures with two candidate explanations each, and score the pointwise and contrastive protocols on identical data.
2. Does a fixed, planner-free workflow match an LLM-planned run on success while cutting model calls, for a recurring local task? First step: pick one recurring procedure, record 10 planned runs' step sequences, and check whether they are identical enough to pin as a fixed workflow.

All points above are based on abstracts only. No full-text reading was done, and the claims about these papers' results are unverified.
